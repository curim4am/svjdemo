# Ukázka – SVJ Buková (schůze, usnesení, úkoly, zápis)

- **index.html** – ukázková verze aplikace s vymyšlenými daty (6 schůzí, usnesení, úkoly, zápisy). Stačí otevřít v prohlížeči. Žlutý pruh nahoře označuje ukázku, tlačítkem **↺ Obnovit ukázku** vrátíte původní data. Ukázka ukládá data odděleně – nepřepíše skutečnou aplikaci.
- **svj_demo_zaloha.json** – stejná ukázková data jako záloha. Lze je nahrát do běžné aplikace přes **Nastavení → Obnovit ze zálohy** (pozor, nahradí data v prohlížeči).

Všechna jména jsou smyšlená – ukázku lze bezpečně sdílet nebo zveřejnit.
